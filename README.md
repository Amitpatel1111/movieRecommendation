# 🎬 Movie Recommendation System

A content-based movie recommender system that suggests similar movies based on user input. Built using Python, Pandas, Scikit-learn, and TMDB datasets.

---

---

## 📌 Features

- Suggests movies based on content similarity (title, genre, overview).
- Uses TF-IDF and cosine similarity for recommendation logic.
- Precomputed similarity matrix for fast recommendations.
- Clean and interactive notebook format.

---

## 📊 Dataset

- **TMDB 5000 Movies & Credits**
- Source: [Kaggle](https://www.kaggle.com/datasets/tmdb/tmdb-movie-metadata)
